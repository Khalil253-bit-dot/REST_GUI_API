# What I learned

The steps for this assignment were very straightforward once I gained a cursory understanding of the syntax being used.
The steps were as follows

1. I instantiated new price_var, PID_var, and Desc_var variables to hold the new values asked for
2. I deleted the age variable, the age section of the validate() function, and the snippet for the age field
3. I added a new snippet in validate() that checks price_var to make sure it is between 0 and 1000
4. I coded new fields for the price, ID, and description variables
5. I changed the newsletter variable to a purchase variable and asked: Is this an in-store purchase?

The tips I picked up from assignment 1 came in handy for this assignment. The changes were made quickly because
there was already a framework established, so VScode detected the change in code early and suggested new syntax
to make the program run. I did not realize that validation could be hard coded into a method and used 
throughout the program in a validate() call. That is a useful tool for writing more robust, modular code.
